# Суть — доска модели и дорожной карты

Живая страница: модель, этапы, экономика, карта модулей, метрики, риски, решения.
Страница собирается из файлов `content/` — вёрстку для правок трогать не нужно.

## Как править (для человека и ИИ-агента)
| Хочу | Что делать |
|---|---|
| Поменять текст, цифру, цену | открыть нужный файл в `content/blocks/` и поменять значение |
| Добавить этап, карточку, строку таблицы, решение, метрику | добавить объект в массив `items` / `rows` этого файла |
| Добавить модуль | добавить строку в нужную группу `content/blocks/modules.json` (поля: id, name, who, what, cost, price, stage, priority, now) |
| Отметить решение | в `decisions.json` поставить `"done": true` и написать `"answer"` |
| Обновить метрику | в `metrics.json` поменять `value` и `status` (plan / ok / warn / bad) |
| Добавить новый раздел | создать файл в `content/blocks/` и добавить строку в `content/site.json` → `blocks` (id, type, src, nav) |
| Поменять порядок разделов | переставить строки в `content/site.json` → `blocks` |
| Новое возражение и ответ | добавить строку в `content/blocks/faq.json` → `items` (кто спросил, статус, возражение, ответ, чем проверяем) |
| Пересчитать сценарии сети | `python3 инструменты/сеть_по_месяцам.py` в папке модели, перенести цифры в `funnel.json`, `ramp.json`, `economics.json` |
| Записать, что поменялось | добавить строку сверху в `content/blocks/log.json` и обновить `updated` в `site.json` |

**Типы разделов** (у каждого свой файл в `content/blocks/`, посмотреть пример — открыть файл):

| Тип | Что рисует | Главные поля |
|---|---|---|
| `hero` | шапка: заголовок, орбита, 4 цифры | `title`, `lead`, `stats[]` (`kind`: ring / dots / plain, `value`, `of`, `big`, `label`, `icon`) |
| `flow` | схема «метод → продукт → специалист → клиент» | `nodes[]` (`icon`, `title`, `text`), `gets[]` |
| `cards` | карточки | `items[]` (`icon`, `title`, `text`) |
| `roadmap` | дорожка этапов, клик — подробности | `items[]` (`n`, `title`, `short`, `status`: сейчас / далее, `icon`, `goal`, `segments`, `do`, `money`, `exit`), `sequence` |
| `split` | полоса «кому сколько с продажи» | `total`, `parts[]` (`key`: spec / platform / cost, `label`, `value`, `note`), `also[]` |
| `funnel` | воронка с переключателем сценариев | `steps[]`, `scenarios[]` (`name`, `values[]` — по числу шагов, `money`, `default`) |
| `bars` | горизонтальные полосы сравнения | `unit`, `max`, `items[]` (`label`, `value`, `note`, `ours`) |
| `pricing` | тарифы | `free[]`, `plans[]` (`name`, `price`, `per`, `features`, `icon`, `hot`), `extra` |
| `slider` | ползунок скидки от специалиста + плюсы и минусы | `price`, `spec`, `platform`, `cost` (сумма = цене), `steps[]`, `groups[]` (`who`, `icon`, `pros`, `cons`), `avoid`, `verdict` |
| `ramp` | прибыль по месяцам, по панели на сценарий | `scenarios[]` (`name`, `values[12]`, `breakeven`, `year`, `facts`), `note` |
| `faq` | возражения и ответы с фильтрами | `items[]` (`who`, `state`: answer / pilot / proposal / accepted, `q`, `a`, `check`, `note`) |
| `tables` | таблицы; `"collapsed": true` в site.json — свёрнуты | `tables[]` (`title`, `columns`, `rows`, `note`) |
| `modules` | карта модулей с фильтрами | `groups[]` → `rows[]` |
| `metrics` | шкалы метрик | `items[]` (`icon`, `label`, `value`, `target`, `shown`, `target_text`, `status`, `hint`) |
| `risks` | риски с уровнем 1–3 | `items[]` (`icon`, `risk`, `level`, `answer`) |
| `checklist` | открытые решения | `items[]` (`q`, `done`, `answer`) |
| `log` | журнал | `items[]` (`date`, `text`) |
| `markdown` | свободный текст из `.md` | — |

**Иконки** — имена из набора Lucide (https://lucide.dev/icons), например `book-open`, `users`, `wallet`.
**В текстах:** `**жирный**`, `_акцент_` (курсив), `` `код` ``. Метки ❓ ✅ ⚠️ 🔴 🟡 ⚪ сами превращаются в значки — их можно писать как есть. HTML в данных не нужен.
**Поле `_help`** в файле — подсказка для правящего, на странице не показывается.

## Правила, чтобы ничего не потерять
1. Перед отправкой — `python3 tools/check.py`: проверяет, что все файлы читаются и у блоков есть нужные поля.
2. Каждая правка — отдельный коммит с понятным сообщением; история в git хранит все прошлые версии.
3. Если один файл сломан, страница покажет на его месте красную карточку с именем файла — остальные разделы продолжат работать.
4. `index.html`, `assets/app.js`, `assets/style.css` — оболочка; трогать только чтобы добавить новый тип раздела или поменять дизайн.

## Посмотреть локально
```
python3 -m http.server 8000   # затем открыть http://localhost:8000
```
(Двойной клик по index.html не сработает: браузер не даёт читать файлы без сервера.)
